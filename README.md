# 江湖撤离录（Web MVP）

手机竖屏单机文字武侠 RPG：在青石镇探听、整备，潜入黑风寨取物，再从有不同条件与代价的路线撤离。首版地图仅有青石镇和黑风寨；不含账号、云同步或联机。

## 运行

需要 Node.js 22+ 与 npm。

```powershell
npm ci
npm run dev
```

终端会显示本地访问地址。在手机浏览器调试时建议使用 360～430 CSS px 竖屏宽度。

## 验证

```powershell
npm run typecheck
npx vitest run
npx playwright install chromium
npm run test:e2e
npm run build
```

`npm run test:e2e` 会自行启动测试用开发服务器；测试使用 390×844 触控视口，并额外检查 360/390/430 三档宽度。

## 游玩路径

茶馆探听“西域经书的传闻” → 整备出发 → 西仓核实消息并抄录二当家独行时辰 → 偏房交战 → 取得《血刀经·残页》 → 当场收手撤离，或继续进入寨主密室。带回燕回身、龟息功等秘籍后，可在镇中练功处参悟；能力会影响战斗与特殊撤离路线。风声、负重与物资损失均由所选行动决定。

山门、悬崖、水道、商队和后山密道共五条撤离路线。商队在风声 50–64 需要主动掷 1d6 达到 4+，65–79 需要 5+；失败仍扣 200 两并增加 10 风声。掷骰结果与下一随机种子会自动保存，刷新无法重掷同一次结果。

探索页可展开地图、行囊、撤离局势与行动日志。战斗中可切换已学招式；显眼招式若被存活对手目击，镇上传闻会出现未确认消息，下一局山门盘查门槛从风声 50 降至 40。

## 存档

无需账号，游戏自动保存在当前浏览器本地。青石镇的“存档 · 导入与导出”可导出 JSON 备份；导入会先校验，需再次确认才会替换进度。清除浏览器网站数据会丢失本地存档，请定期导出。双份存档损坏时会进入保护页，不会静默清档。

## 项目结构

- `src/game/engine/`：状态、战斗、风声、武学、撤离和结算规则。
- `src/game/content/`：地点、事件、人物、物品、武学与情报 JSON，以及引用/可达性校验。
- `src/ui/`：青石镇、情报、整备、探索、战斗、结算与故障页面。
- `src/assets/`：项目内置的 AI 生成竖屏场景图；游戏文字与按钮均由前端独立渲染。
- `e2e/`：真实浏览器完整流程和手机视口检查。

图像使用内置 imagegen 生成。`black-wind-stronghold.png` 的提示词主题为“黑风寨雨夜、冷蓝月色、湿石路、山寨灯火、小比例侠客剪影，无文字与水印”；`town-dawn.png` 的提示词主题为“青石镇晨景、石街、茶馆药铺、远山薄雾、小比例独行侠客，无文字与水印”。
