# 江湖撤离录（Web MVP）

手机竖屏单机文字武侠 RPG：在青石镇探听、整备，探索黑风寨或青燕门旧址，再从有不同条件与代价的路线撤离。不含账号、云同步或联机。

## 运行

需要 Node.js 22+ 与 npm。

### Windows 一键启动

双击项目根目录的 `启动游戏.cmd`。脚本会在首次运行时安装依赖，启动开发服务器，并自动打开浏览器。关闭脚本窗口即可停止服务器。

服务器优先使用 5280 端口。如果该端口已被其他程序占用，Vite 会自动选择 5281、5282 等空闲端口；请以终端显示和浏览器打开的实际地址为准。

### 手动启动

```powershell
npm ci
npm run dev
```

开发服务默认监听所有网卡的 5280 端口。电脑可打开 `http://127.0.0.1:5280/`；同一局域网内的手机可使用终端显示的无线网 IPv4 地址，例如 `http://192.168.3.43:5280/`。手机浏览器调试时建议使用 360～430 CSS px 竖屏宽度。

## 验证

```powershell
npm run typecheck
npx vitest run
npx playwright install chromium
npm run test:e2e
npm run build
```

`npm run test:e2e` 会自行启动测试用开发服务器；测试使用 390×844 触控视口，并额外检查 360/390/430 三档宽度。

## 游玩路径

打开游戏先进入标题页，点击“开始游戏”后选择存档。空档会从青石镇开启新游戏；已有存档会继续上次进度。首次游玩会显示新手指引，按当前目标从茶馆探听线索、整备、潜入西仓、迎战二当家、取走残页并撤离。推荐操作会标出；可以自由探索或随时跳过。刷新后重新选择存档，指引会随该存档继续，提前撤离或失手后仍会引导下一局，带回残页后结束。

茶馆探听“西域经书的传闻” → 整备出发 → 西仓核实消息并抄录二当家独行时辰 → 偏房交战 → 取得《血刀经·残页》 → 当场收手撤离，或继续进入寨主密室。西仓只有一份《燕回身》镖师手抄本；带回练功处研读，可学会燕回身和镖师的见解，书仍收藏在家。第一次探索黑风寨归来后可探听青燕门旧址，在独立地图寻找《燕回身》原本。先读哪一本都能学会武学，后读另一本会再得到不同见解。其他武学手抄本散落在镇中人物手里，每份只会转手一次。

探索时可在有藏身处的地点避开视线。风声低于 50、光线与场地合适时，可冒着巡逻打断的风险研读随身秘籍。整备时可选择是否带出家藏独本。行囊有 12 格容量，物品占 1～2 格；穿戴和贴身物品不占行囊格，但仍计入 30 负重。行囊里可逐件查看、丢下物品，并在本局返回该地点时拾回。失手后神秘人会救你回镇：留在家中的收藏、穿戴装备和贴身小物保留；行囊、携银及未收好的独本会遗落。独本可在失手地点找回，不会在原来源再次出现。

山门、悬崖、水道、商队和后山密道共五条撤离路线。商队在风声 50–64 需要主动掷 1d6 达到 4+，65–79 需要 5+；失败仍扣 200 两并增加 10 风声。掷骰结果与下一随机种子会自动保存，刷新无法重掷同一次结果。

探索页将场景文字和最新行动结果保留在上方，“眼前的事”与“前往别处”各自滚动；选择后的叙事和实际变化可从行动日志回看。底部可展开地图、行囊、撤离局势与日志。战斗中可切换已学招式；显眼招式若被存活对手目击，镇上传闻会出现未确认消息，下一局山门盘查门槛从风声 50 降至 40。

## 存档

无需账号，三个独立档位自动保存在当前浏览器本地。原有单档进度直接显示在第一档。存档选择页可将已有档位重新开局，确认时会先下载该档备份。青石镇的“存档 · 导入与导出”可导出当前档位的 JSON 备份；导入会先校验，需再次确认才会替换当前档位。清除浏览器网站数据会丢失本地存档，请定期导出。某档位的双份存档损坏时会进入保护页，其他档位仍可使用。

## 项目结构

- `src/game/engine/`：状态、战斗、风声、武学、撤离和结算规则。
- `src/game/content/`：地点、事件、人物、物品、武学与情报 JSON，以及引用/可达性校验。
- `src/ui/`：青石镇、情报、整备、探索、战斗、结算与故障页面。
- `src/assets/`：项目内置的原创像素风竖屏场景图；游戏文字与按钮均由前端独立渲染。
- `e2e/`：真实浏览器完整流程和手机视口检查。

当前界面使用内置 imagegen 生成的 `town-pixel.png`（晨间江湖小镇、茶馆与石板路）和 `stronghold-pixel.png`（月夜山寨、栈道与灯火）。两张图片均不包含游戏文字或按钮；界面元素由 CSS 和 React 渲染。
