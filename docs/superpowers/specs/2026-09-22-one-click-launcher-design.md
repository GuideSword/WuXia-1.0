# Windows 一键启动脚本设计

## 目标

在项目根目录提供 `启动游戏.cmd`。Windows 用户双击该文件即可安装缺失依赖、启动本地开发服务器并自动打开游戏页面；关闭脚本窗口时，游戏服务器随之停止。

## 启动流程

1. 脚本使用自身所在目录作为工作目录，避免用户从快捷方式或其他目录启动时找不到项目文件。
2. 依次检查 `node` 和 `npm` 命令。任一命令缺失时，显示需要安装 Node.js 22 或更高版本的中文提示，等待用户按键后退出。
3. 如果 `node_modules` 不存在，执行 `npm ci`。安装失败时显示错误提示，等待用户按键后退出。
4. 执行 `npm run dev -- --open http://127.0.0.1:5280/`。Vite 在服务就绪后打开默认浏览器，开发服务器持续占用当前窗口。
5. 用户关闭脚本窗口或在窗口中按 `Ctrl+C` 时，前台 npm/Vite 进程结束，服务器停止。

## 文件变更

- 新增根目录 `启动游戏.cmd`。
- 更新 `README.md` 的运行说明，优先介绍双击启动，并保留手动执行 npm 命令的方法。

## 错误处理

- 缺少 Node.js 或 npm：给出安装要求和处理建议。
- 依赖安装失败：保留 npm 输出，显示失败说明并暂停窗口，方便用户查看原因。
- 开发服务器异常退出：显示退出状态并暂停窗口，避免错误信息一闪而过。

## 验证

- 在已安装依赖的环境双击脚本，确认服务监听 5280 端口并打开游戏页面。
- 临时模拟缺少依赖目录，确认脚本会调用 `npm ci`。
- 模拟找不到 Node.js，确认脚本显示提示且不会继续启动。
- 关闭脚本窗口后，确认 5280 端口不再提供服务。

## 范围

脚本面向 Windows 双击使用，不增加常驻后台服务、桌面快捷方式或生产构建服务器。
